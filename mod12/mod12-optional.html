std::optional

Representing values that may or may not be present.

The Big Picture

std::optional is a C++17 feature that provides a way to represent optional, or nullable, values. It either contains a value or it is empty.

This makes std::optional useful for functions that may not always return a meaningful result. Instead of sentinel values or error codes, the caller can explicitly check whether a value is present.

Example: Safe Division

This example returns an optional value from a division function. A valid result is returned when the denominator is nonzero; otherwise the function returns std::nullopt.

#include <iostream>
#include <optional>
#include <string>

// Function that returns an optional double after dividing two numbers
std::optional<double> divide(double numerator, double denominator)
{
    if (denominator == 0.0)
    {
        return std::nullopt; // Division by zero is not allowed
    }
    else
    {
        return numerator / denominator;
    }
}

int main()
{
    double num = 10.0;
    double denom = 0.0; // Change this to a non-zero value to get a valid result
    std::optional<double> result = divide(num, denom);

    if (result.has_value())
    {
        std::cout << "Result of division: " << result.value() << std::endl;
    }
    else
    {
        std::cout << "Division by zero is not allowed." << std::endl;
    }

    return 0;
}
