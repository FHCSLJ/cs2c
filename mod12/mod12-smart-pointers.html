Smart Pointers

Automatic lifetime management with std::unique_ptr, std::shared_ptr, and std::weak_ptr.

The Big Picture

Smart pointers help manage dynamic memory automatically, ensuring proper resource deallocation and avoiding some of the pitfalls of manual memory management.

Modern C++ provides several smart pointer types with different ownership models. The three most important are std::unique_ptr, std::shared_ptr, and std::weak_ptr.

std::unique_ptr

A std::unique_ptr owns a dynamically allocated object exclusively. It cannot be copied, but it can be moved. When the smart pointer goes out of scope, the resource is automatically destroyed.

#include <iostream>
#include <memory>

int main()
{
    size_t size = 10; // could be determined at runtime
    std::unique_ptr<int[]> arr(new int[size]);

    for (size_t i = 0; i < size; ++i)
    {
        arr[i] = i * i;
    }

    for (size_t i = 0; i < size; ++i)
    {
        std::cout << arr[i] << " ";
    }

    std::cout << std::endl;
    // No need to delete[] arr, it will be automatically deallocated
}

std::shared_ptr

A std::shared_ptr uses reference counting so multiple parts of a program can share ownership of the same resource. The resource is deallocated when the last owning shared_ptr is destroyed.

#include <iostream>
#include <memory>

class Resource
{
public:
    Resource() { std::cout << "Resource acquired\n"; }
    ~Resource() { std::cout << "Resource destroyed\n"; }
    void do_important_things() { std::cout << "Doing important things!\n"; }
};

void use_resource(std::shared_ptr<Resource> resource)
{
    resource->do_important_things();
}

int main()
{
    std::shared_ptr<Resource> res1 = std::make_shared<Resource>();
    std::cout << "Resource use count: " << res1.use_count() << std::endl;
    use_resource(res1);

    // separate scope in which to share the shared_ptr
    {
        std::shared_ptr<Resource> res2 = res1;
        std::cout << "Resource use count: " << res1.use_count() << std::endl;
        use_resource(res2);
    }

    std::cout << "Resource use count: " << res1.use_count() << std::endl;
}

Expected output:

Resource acquired
Resource use count: 1
Doing important things!
Resource use count: 2
Doing important things!
Resource use count: 1
Resource destroyed

std::weak_ptr

A std::weak_ptr holds a non-owning reference to a resource managed by std::shared_ptr. It is especially useful for observing a shared resource without extending its lifetime and for avoiding circular ownership.

#include <iostream>
#include <memory>

class Resource
{
public:
    Resource() { std::cout << "Resource acquired\n"; }
    ~Resource() { std::cout << "Resource destroyed\n"; }
    void do_important_things() { std::cout << "Doing important things!\n"; }
};

void observe_resource(std::weak_ptr<Resource> weak_res)
{
    if (std::shared_ptr<Resource> res = weak_res.lock())
    {
        std::cout << "Using weak_ptr: Resource is still alive\n";
        res->do_important_things();
    }
    else
    {
        std::cout << "Using weak_ptr: Resource has been destroyed, can't do important things -- must not be that important.\n";
    }
}

int main()
{
    std::shared_ptr<Resource> res1 = std::make_shared<Resource>();
    std::weak_ptr<Resource> weak_res = res1;

    observe_resource(weak_res);

    res1.reset();

    observe_resource(weak_res);

    return 0;
}

Expected output:

Resource acquired
Using weak_ptr: Resource is still alive
Doing important things!
Resource destroyed
Using weak_ptr: Resource has been destroyed, can't do important things -- must not be that important.
