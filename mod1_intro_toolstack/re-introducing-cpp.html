What Is C++?

C++ is a high-level, strictly typed, memory unsafe (ooh, that sounds scary), compiled, general-purpose programming language specified by an ANSI/ISO C++ standard (woa, that’s a mouthful!). It is a superset of the C programming language and introduces the object-oriented programming (OOP) paradigm to C. It is known for its performance and is used all over the place, from large software projects (e.g. browsers and video games) to small embedded devices where efficiency matters. C++ differs from many other high-level programming languages in that it allows the developer direct control over memory management. And you know what they say, with great power comes great responsibility!

Why “Memory Unsafe”?

Unlike languages such as Java or Python, C++ does not automatically prevent you from accessing memory you shouldn’t. This is a feature as much as it is a hazard: it enables fine-grained control and high performance, but it also means bugs like buffer overflows and dangling pointers are your responsibility to prevent and catch. Valgrind is one of our tools for doing exactly that.
