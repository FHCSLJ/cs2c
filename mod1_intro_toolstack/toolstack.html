The Toolstack

The tools, platforms, and environment we use to develop C++ professionally throughout this course.

What You Need to Develop C++

In this module, we will familiarize ourselves with what we might call the toolstack for the course. Developing C++ professionally isn’t just a compiler and a text editor — there are several layers involved, and each one has a job:

# What you need What we use
1 A machine to work on Your machine + a Linux virtual machine via GitHub Codespaces
2 An editor or IDE to write source code VSCode, running inside the Codespace
3 A compiler (+ assembler and linker) to produce an executable g++
4 A build system to manage compilation details make
5 A build system generator to manage the build system CMake
6 Version control to track files and history Git and GitHub
7 A way to run and test our programs VSCode terminal, CTest, and Catch2

If you’re continuing on from my 2A and/or 2B course, much of this is old news. But if you’re joining us for the first time, this might feel like an avalanche of new stuff. No worries! While this might feel like a lot of tooling up front, our course development environment abstracts away most of these layers so we can stay focused on the C++.

Configuration as Code

There’s actually code that sets up our development environments. This is known as “configuration as code,” and there’s been a lot of interest and activity in this space recently, which is fantastic because we get to use it, benefit from it, and learn about it!

What This Means for You

When you open the course repository in a GitHub Codespace, the environment is built automatically from a configuration file in the repo. Every student gets the same compiler, the same tools, and the same setup — no installation required on your end, and no “it works on my machine” surprises.
