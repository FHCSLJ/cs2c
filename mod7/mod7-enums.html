Enumeration Types

Named constants, type safety, and a robot that knows which way it’s facing.

The Big Picture

Enumeration types (enums) are a lot like a list of declared constants. Defining an enum is like defining a new integral type where a variable of that type can only take on a restricted set of values, and we get to pick the names for those values. Enums are extremely handy for representing a fixed set of identifiers.

Enumeration type (enum)
A user-defined type whose values are drawn from a named set of integer constants. The compiler enforces that a variable of an enum type can only be assigned values from that set, providing compile-time type checking that raw integers cannot.

Motivation: The Robot Problem

Suppose we have a class Robot with an attribute facing that holds the cardinal direction the robot is currently facing. We have a few options for how to represent it.

We could use a string and assign values like "North", "East", etc. But without extra validation, "Norht" or "NW" could easily sneak in. We could use an int with an implicit mapping (0 = North, 1 = East, ...), but that makes the code unreadable. We could define named constants:

const int NORTH = 0;
const int EAST  = 1;
const int SOUTH = 2;
const int WEST  = 3;

That is a real improvement. But these four constants have no formal relationship to each other, and facing is still just an int that the compiler will happily let you assign any integer to. An enum groups them into a single named type and lets the compiler help catch mistakes.

Declaring and Using an Enum

We declare the new type like this:

enum Direction
{
    NORTH,
    EAST,
    SOUTH,
    WEST
};

A variable of type Direction can only be assigned values from that set:

Direction facing;

facing = NORTH;

// later ...

facing = EAST;

And we can test its value to make decisions:

if (facing == SOUTH)
{
    // Statements
}

Underlying Integer Values

Each enumeration constant maps to an integer. By default, values start at 0 and increment by 1, so the declaration above is equivalent to:

enum Direction
{
    NORTH = 0,
    EAST  = 1,
    SOUTH = 2,
    WEST  = 3
};

You can assign explicit values to any or all of the constants:

enum Direction
{
    NORTH = 0,
    EAST  = 12,
    SOUTH = 23,
    WEST  = 34
};

You can also assign values to only some constants. Unassigned constants receive the next consecutive value after the preceding one:

enum Direction
{
    NORTH = 7,
    EAST,        // 8
    SOUTH = 20,
    WEST         // 21
};

Whether the underlying values matter depends on the use case. Often the names are all you need, and the integers are just an implementation detail.
