Tree Sort

Concept

Tree Sort uses a binary search tree to sort elements:

  1. Insert all elements into a BST.
  2. Perform an in-order traversal to read them back in sorted order.

Tree Sort combines the principles of BSTs with sorting and provides a natural approach when you are already working with tree-based data structures. Note that worst-case O(n²) applies to an unbalanced BST. Using a self-balancing tree such as std::multiset (a red-black tree) guarantees O(n log n) in all cases.

Pseudocode

procedure tree_sort(A: list of sortable items)
    create an empty binary search tree
    for each element in A
        insert element into the tree
    perform in-order traversal and copy elements back to A
end procedure

Implementation

// Using std::multiset (red-black tree) as the BST
template <typename Iterator>
void tree_sort(Iterator begin, Iterator end)
{
    using T = typename std::iterator_traits<Iterator>::value_type;
    std::multiset<T> tree(begin, end);
    std::copy(tree.begin(), tree.end(), begin);
}

Bubble Sort

Concept

Bubble Sort is one of the simplest sorting algorithms. It repeatedly steps through the list, compares adjacent elements, and swaps them if they are out of order. Each full pass moves the next-largest unsorted element to its final position, as if it “bubbles” to the top.

Pseudocode

procedure bubble_sort(A: list of sortable items)
    n = length(A)
    for i from 0 to n-1
        for j from 0 to n-i-2
            if A[j] > A[j+1]
                swap(A[j], A[j+1])
        end for
    end for
end procedure

Implementation

template <typename Iterator>
void bubble_sort(Iterator begin, Iterator end)
{
    if (begin == end)
        return;

    for (auto i = begin; i != end; ++i)
    {
        for (auto j = begin; j != std::prev(end, std::distance(begin, i) + 1); ++j)
        {
            if (*(j + 1) < *j)
                std::iter_swap(j, j + 1);
        }
    }
}

Selection Sort

Concept

Selection Sort divides the array into a sorted prefix and an unsorted remainder. On each pass, it finds the minimum element in the unsorted portion and swaps it to the front of that portion, growing the sorted prefix by one.

Pseudocode

procedure selection_sort(A: list of sortable items)
    n = length(A)
    for i from 0 to n-1
        min_index = i
        for j from i+1 to n-1
            if A[j] < A[min_index]
                min_index = j
        if min_index != i
            swap(A[i], A[min_index])
    end for
end procedure

Implementation

template <typename Iterator>
void selection_sort(Iterator begin, Iterator end)
{
    for (auto i = begin; i != end; ++i)
    {
        auto min_elem = i;
        for (auto j = std::next(i); j != end; ++j)
        {
            if (*j < *min_elem)
                min_elem = j;
        }
        std::iter_swap(i, min_elem);
    }
}

Insertion Sort

Concept

Insertion Sort builds the sorted array one element at a time. It takes each new element and shifts it leftward into its correct position among the already-sorted elements. Think of sorting a hand of playing cards: you pick up one card at a time and slip it into the right spot among the cards already in your hand.

Insertion Sort is notably efficient for small or nearly-sorted data, which is why it appears as a base case in several hybrid sorting algorithms.

Pseudocode

procedure insertion_sort(A: list of sortable items)
    n = length(A)
    for i from 1 to n-1
        key = A[i]
        j = i - 1
        while j >= 0 and A[j] > key
            A[j+1] = A[j]
            j = j - 1
        A[j+1] = key
    end for
end procedure

Implementation

template <typename Iterator>
void insertion_sort(Iterator begin, Iterator end)
{
    if (begin == end)
        return;

    for (auto i = std::next(begin); i != end; ++i)
    {
        auto key = *i;
        auto j = i;

        while (j != begin && *(std::prev(j)) > key)
        {
            *j = *(std::prev(j));
            --j;
        }

        *j = key;
    }
}

Merge Sort

Concept

Merge Sort follows the divide-and-conquer strategy:

  1. Divide: Split the array in half recursively until each sub-array contains a single element (trivially sorted).
  2. Conquer: Merge pairs of sorted sub-arrays into a single sorted array, working back up to the full size.

Merge Sort guarantees O(n log n) in all cases and is stable, but requires O(n) extra space for the temporary arrays used during merging.

Pseudocode

procedure merge_sort(A, start, end)
    if end - start > 1
        middle = (start + end) / 2
        merge_sort(A, start, middle)
        merge_sort(A, middle, end)
        merge(A, start, middle, end)
    end if
end procedure

procedure merge(A, start, middle, end)
    copy A[start..middle] into temporary array L
    copy A[middle..end]   into temporary array R

    i = 0, j = 0, k = start
    while i < length(L) and j < length(R)
        if L[i] <= R[j]: A[k] = L[i]; i++
        else:             A[k] = R[j]; j++
        k++

    copy any remaining elements of L (or R) back to A
end procedure

Implementation

template <typename Iterator>
void merge(Iterator begin, Iterator middle, Iterator end)
{
    using T = typename std::iterator_traits<Iterator>::value_type;

    auto left_size  = std::distance(begin, middle);
    auto right_size = std::distance(middle, end);

    std::vector<T> left(left_size);
    std::vector<T> right(right_size);

    std::copy(begin,  middle, left.begin());
    std::copy(middle, end,    right.begin());

    auto i = 0, j = 0;
    Iterator k = begin;

    while (i < left_size && j < right_size)
    {
        if (left[i] <= right[j])
            *k = left[i++];
        else
            *k = right[j++];
        ++k;
    }

    while (i < left_size)  { *k = left[i++];  ++k; }
    while (j < right_size) { *k = right[j++]; ++k; }
}

template <typename Iterator>
void merge_sort(Iterator begin, Iterator end)
{
    if (std::distance(begin, end) > 1)
    {
        auto middle = std::next(begin, std::distance(begin, end) / 2);
        merge_sort(begin, middle);
        merge_sort(middle, end);
        merge(begin, middle, end);
    }
}

Quick Sort

Concept

Quick Sort is another divide-and-conquer algorithm:

  1. Choose a pivot element from the array.
  2. Partition the array using the pivot value.
  3. Recursively sort the two partitions.

Quick Sort’s average case is O(n log n) and it sorts in-place (O(log n) stack space for recursion). In practice it tends to be faster than other O(n log n) algorithms due to small constant factors and excellent cache behavior. Its weakness is a worst case of O(n²), which occurs when pivot selection consistently produces highly unbalanced partitions (for example, always picking the smallest or largest element).

Comparative Analysis

Algorithm Best Case Average Case Worst Case Space Stable?
Bubble Sort O(n) O(n²) O(n²) O(1) Yes
Selection Sort O(n²) O(n²) O(n²) O(1) No
Insertion Sort O(n) O(n²) O(n²) O(1) Yes
Merge Sort O(n log n) O(n log n) O(n log n) O(n) Yes
Quick Sort O(n log n) O(n log n) O(n²) O(log n) No
Tree Sort O(n log n) O(n log n) O(n²)* O(n) Yes

* Worst case for tree sort assumes an unbalanced BST. Using std::multiset (red-black tree) guarantees O(n log n) in all cases.

Observations

Simple algorithms (Bubble, Selection, Insertion) are easy to implement and perfectly reasonable for small datasets (roughly under 50 elements). Among these, Insertion Sort stands out: its O(n) best case makes it surprisingly fast on nearly-sorted data, which is why it appears as a base case in hybrid algorithms.

Divide-and-conquer algorithms (Merge Sort, Quick Sort) scale much better to large datasets. Merge Sort gives consistent O(n log n) at the cost of O(n) extra memory. Quick Sort is typically fastest in practice but requires a good pivot strategy to avoid its O(n²) worst case.

Tree Sort is most natural when your data is already tree-shaped or when you need a sorted data structure anyway. Using std::multiset makes the implementation almost trivially simple.

Under the Hood: std::sort

The C++ standard does not mandate a specific algorithm for std::sort, only that it run in O(n log n) time. In practice, most standard library implementations use a hybrid algorithm called Introsort:

  • Start with quicksort for its speed in the average case.
  • Switch to heapsort when recursion depth exceeds a threshold, preventing the O(n²) worst case.
  • Switch to insertion sort when a partition shrinks below a small threshold (typically around 16 elements), where its low overhead wins.
